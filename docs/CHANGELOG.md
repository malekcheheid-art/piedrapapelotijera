# Changelog

## v1.0.0
- Creacion inicial del juego Piedra, Papel o Tijera.
- Implementacion de persistencia en disco con `ofstream` (modo `ios::app`) y `ifstream`.
- Estructura `Partida` con ID, jugador, eleccion del jugador, eleccion de IA y resultado.
- Menu principal con opciones de jugar, ver historial y salir.
